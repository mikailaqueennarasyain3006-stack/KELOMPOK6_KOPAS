KOS BUK YEN - HALAMAN BERANDA PHP

Struktur:
kos_buk_yen_beranda/
  index.php
  css/
    style.css

Cara menjalankan:
1. Pastikan XAMPP sudah terpasang.
2. Salin folder kos_buk_yen_beranda ke C:\xampp\htdocs\
3. Jalankan Apache dari XAMPP Control Panel.
4. Buka browser dan ketik:
   http://localhost/kos_buk_yen_beranda/

Catatan:
- Halaman ini menggunakan PHP untuk menampilkan kartu kamar dari array sementara.
- Database MySQL belum dihubungkan. Data kamar masih contoh.
- Foto kamar diambil dari Unsplash sehingga perlu koneksi internet.
- Link Informasi Kos, Testimoni, Login, dan Detail Kos disiapkan sebagai tujuan halaman tahap berikutnya.
